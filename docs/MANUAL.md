# STARSTRING 星弦　遊戲說明書

你是一顆彗星，身後有一片不斷上升的虛空。整個遊戲只有一個按鍵：**按住**勾住天體繞行，**放開**把自己甩出去。飛得越高，分數越高。

## 操作

| 裝置 | 按住 | 放開 |
|---|---|---|
| 手機、平板 | 手指按住畫面任何地方 | 手指離開 |
| 電腦 | 按住滑鼠左鍵，或按住空白鍵 | 鬆開 |

- 在標題畫面或結算畫面點一下，就開始新的一局。
- 左下角的 ♪ 是靜音鍵。

## 一局怎麼進行

1. 彗星一開始會自己往上飛。
2. 每顆天體外面有一圈淡淡的圓環，那是它的**可勾範圍**。彗星在範圍內時按住，就會用一條光弦勾住它，開始繞圈。同時在好幾顆的範圍內，勾的是最近的那顆。
3. 繞行時軌道會越縮越小、速度越來越快。
4. 放開的瞬間，彗星沿著當下的方向直直飛出去。**放開的時機決定你往哪裡飛**。
5. 飛出去之後速度會慢慢降回平常的巡航速度，所以要趕快找下一顆天體再加速。

繞得越久甩得越遠，但軌道也越貼近天體表面。貪心多繞半圈，常常就是撞上去的那半圈。

## 怎麼會死

| 死因 | 說明 |
|---|---|
| 墜入恆星 | 繞太久，軌道縮到碰到恆星表面；或是自由飛行時直接撞上 |
| 落入黑洞 | 碰到黑洞中心的黑色區域 |
| 被虛空吞噬 | 畫面下方的紫紅色霧氣追上你 |

**虛空**會隨時間越升越快，而且不會被你甩得太遠：你飛得再快，它都會跟在下方一段固定距離之內。在同一顆星旁邊繞太久，一定會被追上。

**左右的藍色邊界**不會讓你死。撞上去會反彈、減速，而且**連擊歸零**。

## 天體

- **恆星**：最常見，各種顏色，玩法都一樣。
- **雙星**：兩顆恆星互相繞著轉，位置一直在變，飛高一點之後才會出現。
- **黑洞**：飛到一定高度後開始出現，只會在場地中央一帶。
  - 自由飛行經過它附近時，會被引力拉偏。
  - 黑洞也可以勾。勾住時軌道縮得比恆星快得多，加速最猛，也最快掉進去。
  - 快被吸進去時，按住勾住它再立刻放開，是把自己甩離的唯一辦法。

## 計分

分數＝**飛到的最高高度**＋**獎勵分**。

| 來源 | 分數 |
|---|---|
| 高度 | 每往上一個單位 10 分（恆星的可勾範圍半徑約 2.6 個單位） |
| 勾住新的天體 | 20 分 × 倍率 |
| 吃到星塵（散落的小光點） | 10 分 × 倍率 |
| 擦邊繞行 | 每秒 40 分 × 倍率 |

**連擊與倍率**

- 每勾住一顆**和上一顆不同**的天體，連擊加 1。放開後再勾回同一顆不算。
- 倍率＝1＋連擊數×0.25。連擊 4 是 ×2，連擊 16 達到上限 ×5。
- 撞到左右邊界，連擊歸零。除此之外連擊不會斷。

**擦邊繞行**：繞行時軌道很貼近天體表面，彗星會變成金色並噴出火花，這段時間持續加分。這是分數最高、也最危險的狀態。

## 畫面上的東西

| 看到的 | 意思 |
|---|---|
| 彗星是青色 | 平常速度 |
| 彗星變洋紅色 | 高速 |
| 彗星變金色、噴火花 | 正在擦邊繞行，持續加分 |
| 天體外的淡色圓環 | 可勾範圍 |
| 圓環變亮 | 現在按住會勾到這一顆 |
| 散落的小光點 | 星塵，碰到就加分 |
| 紫色小亮點（沒有尾巴） | 幽靈彗星，見下方 |
| 左上角大數字 | 目前分數，下面是歷史最佳 |
| 右上角金色數字 | 連擊數與目前倍率 |

## 今日星系與幽靈彗星

- 每天的星圖是固定的，同一天所有人玩到的都是同一張，隔天換一張。標題畫面下方會顯示今天的日期。
- 想指定星圖，在網址後面加 `?seed=任意文字`，例如 `?seed=hello`。同樣的文字永遠是同一張圖，可以拿來和朋友比分數。
- **幽靈彗星**是你在這張星圖上最高分那一局的重播，從第二局開始出現。它在你上方代表你這局落後，被你甩到下方代表你正在超前。它碰不到你，也不影響分數。

## 聲音

- 第一次點擊畫面後才會有聲音，這是瀏覽器的規定。
- 繞行時會聽到一串音，繞得越快音越密。
- 配樂會跟著連擊變化：連擊越高，鼓和琶音等聲部一層一層加入；斷連後再慢慢退場。
- iPhone 沒聲音時，先檢查側邊的靜音開關。

## 紀錄與離線

- 最高分、每張星圖的幽靈、靜音設定都存在這台裝置的瀏覽器裡。清除瀏覽資料、換瀏覽器或用無痕模式，紀錄就不在了。
- 玩過一次之後，沒有網路也能開啟。
- 可以加到主畫面當成 App：iPhone 用 Safari 的「分享 → 加入主畫面」，Android 用 Chrome 選單的「安裝應用程式」。

## 訣竅

- **想往上飛，就在彗星正要往上的那一刻放開**。順時針繞的時候是在天體的左側，逆時針是在右側。
- 前幾局不用繞滿一圈，繞四分之一到半圈就放，先練方向。
- 往場地中間甩。撞牆會斷連擊，高分全靠連擊倍率。
- 放開之前先看下一顆星在哪裡，朝著它的圓環甩。
- 每顆星都只勾一下就走，連擊累積得最快；等倍率高了，再找機會擦邊繞行賺分。
- 虛空逼近時不要回頭勾下方的星。
- 看到黑洞，貼著左右兩側飛比較安全，它的引力範圍碰不到邊界附近。
